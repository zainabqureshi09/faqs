## 🎬 Animations Included

### Animation 1: Pulsing Glow
```
Element:    Circular spotlight
Duration:   4 seconds
Effect:     Gentle scale + opacity change
```

## 🎨 Customization Quick Reference

### Make Title Bigger:
**Line 237 in faq-styles.css:**
```css
.hero-title {
    font-size: 80px;  /* Change from 72px */
}
```

### Make Underline Longer:
**Line 255 in faq-styles.css:**
```css
.hero-title::after {
    width: 350px;  /* Change from 280px */
}
```

### Remove Floating Dot:
**Line 263 in faq-styles.css:**
```css
.hero-title::before {
    display: none;  /* Add this line */
}
```

### Change Animation Speed:
**Line 209 in faq-styles.css:**
```css
animation: pulseGlow 6s ease-in-out infinite;  /* Change from 4s */
```

### Remove All Animations:
**Add to end of hero section:**
```css
.hero-gradient-panel::before {
    animation: none;
}
.hero-title::before {
    animation: none;
}
```

### Make Background Darker:
**Line 134 in faq-styles.css:**
```css
background: #E5E7EB;  /* Change from var(--color-gray-50) */
```
